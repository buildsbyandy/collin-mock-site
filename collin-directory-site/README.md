# Mock Collin College Web Directory

This is a personal project I created to practice front-end development by building a mock version of a Collin College directory site. I used it as a way to get hands-on with:

- **Next.js 15 App Router**
- **Tailwind CSS**
- **Accessible design principles (WCAG-aware)**
- **API integration** (featuring a fun Cat Fact API)

---

## Project Purpose

The goal of this mock-up is to simulate a clean, accessible college web directory that might appear on a real campus site. It's not connected to Collin College in any official way — just something I built to demonstrate what I’ve been learning.

Some of the features I included:

- A simple homepage with CTA links ("Explore Collin" and "About Me")
- A sample "Explore" page with placeholder content and image cards
- A lightweight API widget that pulls in a random cat fact on each refresh
- Branding elements for realism, like the Collin College logo
- Responsive layout using Tailwind's utility-first approach
- Attention to accessibility with semantic HTML and ARIA roles

---

## Tech Stack

- [Next.js](https://nextjs.org/) with the new App Router
- [Tailwind CSS](https://tailwindcss.com/)
- [Cat Fact API](https://catfact.ninja/)
- Built locally using [Cursor](https://cursor.sh/) and VSCode
- Managed with Git (GitHub repo setup in progress)
- Deployment-ready with [Vercel](https://vercel.com/) (optional)
